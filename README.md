## Sprint 7 - Vehicle Dashboard
Aplicación web desarrollada con Streamlit para explorar anuncios de vehículos usados.

## Funcionalidades

- Histograma de la distribución del odómetro.
- Gráfico de dispersión entre precio y odómetro.
- Visualización interactiva mediante Plotly.

## Tecnologías utilizads
- Python
- Pandas
- Plotly
-Streamlit
### Dataset
vehicles_us.csv
